# TDK User Management: Sales Demo Walkthrough Guide

Follow this step-by-step walkthrough during client sales pitches or team demonstrations to show off the full power of the TDK Project-Stack-Resource (PSR) landscape.

---

## Demo Step 1: Landscape Inspection

Show the clean repository layout:

```bash
cd tdk-user-management
ls -la
```

Highlight:
- `Tiltfile`: Loads TDK CLI Starlark utilities.
- `TILT_SERVICE_DEFAULTS.star`: Dynamic port allocator and health check policy.
- `TILT_TECH_STACK.star`: Defines standard stack rules (Bun, Hono, Vite, Biome).
- `services/`: Grouped by domain (`admin`, `portal`, `compliance`).

---

## Demo Step 2: Spin Up the Admin Identity Stack

Run:

```bash
tdk up admin
```

Observe:
- TDK discovers `services/admin/user-admin-api` and `services/admin/user-admin-app`.
- TDK automatically generates `.autogenerated/` plumbing for both resources.
- Tilt opens with live logs and health metrics.

Test live endpoints in terminal or browser:

```bash
# Test SCIM 2.0 Endpoint
curl -s http://localhost:4010/api/v1/scim/v2/Users | jq .

# Test User Directory API
curl -s http://localhost:4010/api/v1/users | jq .
```

---

## Demo Step 3: Spin Up Self-Service & PKCE Portal

Run:

```bash
tdk up portal
```

Test PKCE authorization endpoint:

```bash
curl -s http://localhost:4020/oauth/v2/authorize | jq .
curl -s http://localhost:4020/api/v1/user/sessions | jq .
```

---

## Demo Step 4: Spin Up Governance & Audit Stream

Run:

```bash
tdk up compliance
```

Test Audit stream and observe background worker log ingestion:

```bash
curl -s http://localhost:4030/api/v1/audit/logs | jq .
```

---

## Demo Step 5: Full Landscape Status Check

Run:

```bash
tdk status
```

Demonstrate how TDK displays all 6 resources across the 3 stacks with their dynamic ports, runtime statuses, and dependencies.

---

## Demo Step 6: One-Command Teardown

Run:

```bash
tdk down
```

Show that the environment cleans up gracefully with zero lingering containers or orphan background processes.
